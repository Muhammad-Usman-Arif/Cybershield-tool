Phishing URL Detection Engine

Evaluates URLs for deceptive lexical features, homoglyph characters, entropy spikes, and known credential harvesting patterns.

Key Indicators Monitored:
  • Raw IP address used in place of domain name
  • Presence of deceptive brand keywords in subdomains (e.g. paypal-secure.verify-account.com)
  • Excessive URL string length and Shannon entropy spikes
  • Suspicious URL shorteners and redirect patterns
IP & DNS Spoofing Detection

Validates packet origin authenticity and DNS resolver integrity using RFC standards, hop count TTL heuristics, and recursive resolver comparison.

Detection Logic:
  • RFC 1918 private addresses arriving across WAN boundaries
  • Loopback (127.0.0.0/8) or APIPA (169.254.0.0/16) in transit traffic
  • TTL anomalies indicating forged intermediate hops
  • DGA (Domain Generation Algorithm) entropy and recursive resolver discrepancies
DDoS Traffic Analysis Engine

Hybrid Machine Learning and flow-metric heuristics to detect volumetric floods, SYN floods, UDP amplification, and slowloris exhaustion.

Key Flow Metrics:
  • Packets-per-second (PPS) and bytes-per-second (BPS) velocity
  • SYN-to-ACK ratio imbalance (TCP handshake starvation)
  • Top source IP concentration ratio
  • Destination port diversity vs single-target saturation
Brute Force Detection Engine

Sliding-window temporal log parser capable of ingesting Linux syslog, OpenSSH, Apache/Nginx, Windows Security Events, and PAM auth logs.

Supported Auth Formats:
  • Failed password for root from <IP> port <PORT> ssh2
  • Invalid user <USER> from <IP>
  • HTTP 401 / 403 authorization bursts in web logs
  • Distributed multi-source password spraying patterns
Static Malware Analysis Engine

Safely inspects binary artifacts without execution. Computes cryptographic hashes (SHA-256), validates magic bytes against file extensions, assesses section entropy, and matches YARA signatures.

Safety Guarantee:
  • All uploaded files are subjected strictly to static byte-level inspection.
  • Uploaded artifacts are deleted immediately after cryptographic extraction.
  • Entropy scores above 7.0/8.0 flag potential packers or cryptors (UPX, VMProtect).
